Propósito del Proyecto y Caso de Uso
Modelo de valor de referencia para consistencia estadística

Este sistema implementa un modelo de Machine Learning supervisado (regresión) entrenado con los microdatos de la EAIMCS 2017-2018 (INE Bolivia) para estimar el Ingreso Operativo Anual que una empresa boliviana debería generar a partir de sus variables internas de estructura productiva (personal, sueldos, energía, activos fijos e insumos).

Impacto Contable y Metodológico: Sirve como herramienta de contraste y detección de discrepancias para identificar reportes subvaluados, inconsistentes o atípicos antes de consolidar cuentas del sector empresarial.

Marco Lógico del Proyecto
Resumen ejecutivo basado en marco_logico_ingresos_operativos.md
Fin / Impacto:

Construir estadísticas económicas sectoriales con ingresos declarados contrastados con un valor esperado técnico para auditoría tributaria y consistencia de cuentas nacionales.

Propósito / Objetivo:

Los ingresos operativos anuales declarados cuentan con un valor de referencia derivado de sus factores de producción con R² ≥ 0.70 y error porcentual mediano ≤ 25%.

Componentes del Proyecto:
  • C1: Dataset limpio e integrado a nivel empresa.
  • C2: Análisis exploratorio y diagnóstico de distribuciones.
  • C3: Modelos entrenados y validados (Ridge, Random Forest, HistGradientBoosting).
  • C4: API REST del modelo para inferencia en tiempo real.
  • C5: Dashboard web interactivo con MLOps y monitoreo.
Ficha Técnica del Dataset EAIMCS
Instituto Nacional de Estadística (INE Bolivia)
Catálogo ANDA (INE) BOL-INE-EAIMCS-2017-2018
Período de Referencia Ejercicio Contable 2017 - 2018
Universo Analizado Empresas Medianas y Grandes (10,044 empresas)
Cobertura Territorial Nacional (9 departamentos)
Confidencialidad Decreto Ley 1405 (Datos anonimizados)
Limitaciones Metodológicas: No incluye microempresas ni pequeñas empresas (MIPYMES). La muestra es de carácter dirigido (sin factor de expansión probabilístico) y de corte transversal (no es serie de tiempo).
